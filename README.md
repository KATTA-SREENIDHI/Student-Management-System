# Student Management System

A simple and interactive web-based Student Management System built using HTML, CSS, and JavaScript. It helps manage student records through an easy-to-use interface.

## Features

- Add new student records
- Display student details
- Search students
- Filter students by department and year
- Edit existing student records
- Delete student records
- Store data using browser Local Storage
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Structure

```text
Student-Management-System/
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start managing student records.

## Storage

Student information is stored in the browser's Local Storage, allowing the records to persist after refreshing the page on the same browser.

## Purpose

This project was developed to practice front-end web development, JavaScript DOM manipulation, CRUD operations, and client-side data storage.
